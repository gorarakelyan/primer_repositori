# Fitxa tècnica: [Instal·lació de Visual Studio Code]

## Objectiu
Instal·lar Visual Studio Code en un ordinador i comprovar que funciona correctament.
## Materials
· Ordinador amb Windows.
· Connexió a Internet.
· Visual Studio Code.
## Procediment
1. Obrir el navegador web.
2. Accedir a la pàgina oficial de Visual Studio Code.
3. Descarregar l'instal·lador per a Windows.
4. Executar l'instal·lador.
5. Seguir els passos de la instal·lació.
6. Obrir Visual Studio Code.
7. Crear un fitxer nou i comprovar que es pot editar.
