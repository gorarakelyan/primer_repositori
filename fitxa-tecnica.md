# Fitxa tècnica: [Instal·lació de Visual Studio Code]

## Objectiu
Instal·lar Visual Studio Code en un ordinador i comprovar que funciona correctament.
## Materials
- Ordinador amb Windows.  
- Connexió a Internet.  
- Visual Studio Code.  
```bash
winget install Microsoft.VisualStudioCode
```
## Procediment
1. Obrir el navegador web.
2. Accedir a la pàgina oficial de Visual Studio Code.
3. Descarregar l'instal·lador per a Windows.
4. Executar l'instal·lador.
5. Seguir els passos de la instal·lació.
6. Obrir Visual Studio Code.
7. Crear un fitxer nou i comprovar que es pot editar.

## Comprovacions

- [ ] Visual Studio Code està instal·lat.

- [ ] El programa s'obre correctament.

- [ ] Es pot crear i editar un fitxer.

- [ ] La comanda code --version mostra la versió instal·lada.

## Incidències i solucions

| Incidència | Solució |
|---         |---      |
| L'instal·lador no s'obre    | Tornar a descarregar l'instal·lador. |
| El programa no s'obre    | Reiniciar l'ordinador i provar de nou. |
| La comanda `code` no funciona    | Comprovar que Visual Studio Code està instal·lat correctament. |
